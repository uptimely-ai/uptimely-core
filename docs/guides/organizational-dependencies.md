## People, processes and decisions

Uptimely wires together many technical concepts, but it goes beyond that.

The major bottlenecks, especially in large organiziations, are more about scattered responsbilities, siloed teams and long decision chains. Building even relatively advanced standalone analyical solution is typically the easy part.

Here is how Uptimely Core helps people to boost co-operation.

## Sclaing at the problem source

New solutions often emerge from engineers and business teams across organization. Non-developers hit the wall, when the solution needs to go beyond a few Python scripts.

Uptimely helps taking such solutions one step further.

When the development or data science team is called for help, there is higher change that:

* The solution requirements have been iterated further
* Code structure is understandable thanks to enforced guardrails
* Same framework (Uptimely) can be used also in production

The biggest hurdle is typically that people can not easily build themselves what they need.

## Result validation

Even when data scientists develop solution fast, getting feedback from stakeholders might be struggle.

The data analytics consumers typically see only the results. They have very little help on evaluating if they are using the right data.

Does the solution work? If it seamingly work, are the results correct?

The `Explorer` component in Uptimely Core is meant for that. It gives unified and thoroughly explained documentation and visualizations to explain even the most advanced calculations in understandable way.

## Development dependencies

There are dependencies even between technical teams: Data science, data engineering, devops, software... These might be isolated islands.

As an example, data scientist might need to deploy the work to environment that is vastly different from local setup. They become dependent of the deployment team, and maybe a software team providing internal tooling.

Uptimely Core attempts provide primitive setup that is guaranteed to work the same way in every environment. Also, it aims to ship common functionalities often built by in-house software teams.
