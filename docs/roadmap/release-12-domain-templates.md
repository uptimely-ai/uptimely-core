# Release 12: Domain templates for specifications, configuration, and calculations

This is a planned release grouping, not a published software version.

## Work package: Themes

Provide reusable, domain-specific starting points for analytics projects.

**Prerequisites:** Stable specification, configuration, and function contracts.

| title | breaking | description |
|---|---|---|
| Define versioned domain templates | No | Define selectable, versioned template sets for supported domains and how projects identify a selected template. |
| Add starter specifications and configuration | No | Provide starter specifications and runtime configuration for each supported domain. |
| Add reusable domain calculations | No | Provide reusable functions for common calculations without selecting or running them automatically. |
| Define project overrides | No | Let project-owned configuration and functions override template defaults using documented precedence rules. |
| Document template assumptions and extension points | No | Explain included assumptions, dependencies, customization, and extension points. Adopting a template must not silently add data or run calculations. |
