# Artifacts

Uptimely Core generates documentation and dependency graphs from the
specification so teams can inspect analytics without maintaining separate
descriptions by hand.

- [Automatic Documentation](automatic-documentation.md): generated descriptions of inputs, calculations, and dependencies.
- [Feature Dependency Graph](feature-graph.md): logical lineage and feature-level dependency views.
