# Explorer demo

[Open the Explorer demo](https://uptimely-ai.github.io/uptimely-core/example/){ .md-button .md-button--primary }

The project's demo web explorer is created from the repository's [Data center cooling pump example](https://github.com/uptimely-ai/uptimely-core/tree/main/example).

Explorer consists of web server and front end. This particular demo Explorer is created as a frontend snapshot, so it rans as a static website of only html javascript.

## Run explorer

You can run explorer locally for your own project with the commands described in the docs Quick start and Uptimely Core readme.
